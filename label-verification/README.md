# Next.js App - AI-Powered Alcohol Label Verification

This is the Next.js frontend and API backend for the Alcohol Label Verification App.

Please refer to the main [Workspace README.md](../README.md) at the root of the repository for full documentation, setup instructions, environment variables configuration, system architecture, and project roadmap.

## Getting Started

To run the Next.js app locally:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
